# SMLIE 项目概览

## 项目简介
这是一个综合学习和研究项目库，包含三个主要部分：

### 📚 Learning（学习资料）
- **Machine Learning**: 机器学习学习资源和待办事项
- **Control System**: 控制系统相关材料
- **FPGA**: FPGA设计和测试代码
- **Neuron Science**: 神经科学学习资源

### 📑 Paper（学术论文）
- **fduthesis**: 复旦大学论文模板和相关资源
- **UnderGrdThesis**: 本科毕业论文
- **GeneEditting**: 基因编辑相关论文

### 🔬 Projects（研究项目）
- **Smile_Codes**: SMLM（单分子定位显微镜）相关代码和机器学习应用
  - ML_for_Smile: 深度学习应用于荧光显微镜定位
  - 多个论文复现代码（Challenge2016、DeepSTORM3D、MUFFLE等）
- **Optics**: 光学实验相关项目（相机测试、激光测试等）
- **Dye_database**: 荧光染料数据库
- **Interest**: 兴趣项目（铁路、股票等）

### 🛠️ Toolkits 和参考资源（Ref）
辅助工具和参考材料

## 核心领域
主要聚焦于 **单分子定位显微镜(SMLM)** 及其在荧光显微成像中的应用，包括深度学习算法的研究和实现。
